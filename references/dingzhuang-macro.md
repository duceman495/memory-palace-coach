# 定桩法：宏观 / 微观桩子

来源：第12课（宏观桩子·找桩标准·桩子顺序标准）、第13课（宏观放桩标准）、第14课（实践）、
第15课（微观桩子·案例）、第16课（微观实践）、第17课（宏观微观叠加）

## 方法定义

> 将宏观（微观）物体上的**特征点**作为桩子，按一定顺序排序，并将所记知识点的关键词**出图后依次放桩**记忆。

原理：特征点的顺序你天然记得住（看一遍鹿就知道嘴巴→脚→背→尾巴→脚），
把关键词一一对应放到特征点上，**记住了特征点的顺序就等于记住了关键词的顺序**。

**宏观 vs 微观只差在物体大小**，找桩方法与标准完全相同：

| | 宏观桩子 | 微观桩子 |
|---|---|---|
| 物体 | 单个较大的物体 | 较小的物体 |
| 例 | 摩托车、汽车、坦克、大象、鹿、椅子、桌子、电脑、沙发、电冰箱、垃圾桶、公交站、红绿灯、订书机、打印机、装饰物、大型玩具 | 蚂蚁、蟑螂、蜘蛛、蝴蝶、蜈蚣、指甲刀、订书针、钥匙扣、玩具、发卡、胸针、笔、橡皮、文具盒 |
| 桩子数 | 通常 6～15 个 | 通常 6～12 个 |

> 课程原话：「桩子多的用不完……你随便在你的房间里面少试一下就能够找出几十上百个物体出来」。
> **一本书的记忆，你可能一个房间就搞定了。**

## 出图前置门槛（先过这一关）

> **通用铁律（见 SKILL.md「通用铁律」）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**。

放桩前，每个图像必须先满足 **具体、独立、有大小**，否则放不上去：

- **具体** —— 有明确样子（✗ 天空、平原、大海、住所）
- **独立** —— 能单独成立（✗ 空瓶子、嘴唇）
- **有大小** —— 有体积才能放桩（✗ 国家、地区）

详见 `SKILL.md` 第 3 步。本文件以下所有标准都建立在“图已合格”的前提上。

## 找桩标准

1. **必须是有一定轮廓的特征点**（立体、有形状）
2. **位置和外观相似或对称的特征点，只选一个**作为桩子（如四条一样的桌子腿只取一条）
3. **平面特征点不能作为桩子** —— 标签、贴纸都不行，因为它们不是立体的
4. **桩子要立体，出的图像也要立体**
5. **只在单一物体上寻找**（一个桩物体只在一个物体上找，不跨物体）
6. **非水平方向的桩子可以自行调整到水平方向** —— 如竖直的树干可以想象倒下来变水平，方便放图像

## 桩子顺序规则（5 种）

| 规则 | 适用 | 例 |
|---|---|---|
| **从前到后** | 动物类通用 | 鹿：嘴巴→路脚→背→尾巴→脚 |
| **从上到下** | 直立物体 | 电风扇、伞 |
| **从左到右** | 长条形 | 沙发、凳子 |
| **从里到外** | 容器 | 水缸：缸内→缸口→…… |
| **绕圈补漏** | 单程找不完时 | 大象：从前往后找到尾巴，再**绕回来**补肚子、前腿、脖子 |

> 可组合使用。如椅子 = 从左到右找完 → 再从上到下；组合后能找出 13～15 个桩。

## 放桩标准（6 条）—— **最关键的规则**

1. **图像与图像之间要直接接触**
2. **图像中的其中一个必须和桩子相接触**（不能两个图像都不碰桩子）
3. **图像不能平面化** —— 不能出 APP 图标、不能想象"玻璃上贴着狮子图案"这类二维画面；出图要立体，连接也要立体
4. **桩子上不能同时放多个图像** —— 否则顺序无法确定，必须**依次**放
5. **注意装置上图像的先后顺序** —— 用「图像顺序判断标准」确定
6. **图像连接需要夸张化、动态化、有破坏性**
   > 课程原话：「这三个非常重要」。小物体要**变大或变多**；让图像**动起来**；**充满破坏** —— 这样放上去的图像才牢固。

## 标题与宏观物体的三种连接方式

标题关键词出图后，与桩物体的连接有三种方式（**三种都要掌握**）：

| 方式 | 做法 | 效果 |
|---|---|---|
| **① 直接放在第一个桩上** | 标题图像放到第一个特征点 | 最简单 |
| **② 和整个桩物体用影像故事连接** | 标题图像与整个宏观物体串联成一个故事 | 便于回想"这个知识点是用什么物体记的" |
| **③ 标题图像直接作为桩物体** | 把标题图像本身当作宏观物体，在它身上找桩 | 更好，桩子更贴题 |

例（标题「秦始皇的历史作用」→ 秦 + 作 → 秦始皇、作业本）：
- 方式①：把秦始皇放在反光灯（第一个桩）上
- 方式②：秦始皇坐在电动车上改作业本
- 方式③：把秦始皇本身当宏观物体，在他身上找一串桩

## 宏观微观叠加（第17课）

大量知识记忆策略：宏观桩子和微观桩子**叠加**使用 —— 宏观桩上一个特征点上，再放一个微观物体作为二级桩。
用于单个知识点关键词极多的情况。

## 其他应用技巧（第13课）

- **记忆材料尽量是「主题 + 内容」**（标题 + 答案），这是标准的知识点结构
- **先总结再记忆**，不要直接记零散材料
- **能靠理解记住的就不用记忆法**，不用提取关键词 ——「不要因为你学了记忆法之后看到啥都拿来记」
- 总结：**不改变原有学习方式，只改变背诵方法**

## 交付检查清单

- [ ] 桩物体是**单一物体**吗？
- [ ] 特征点是否**有轮廓、立体**？有没有误用平面特征点（标签/贴纸）？
- [ ] 相似/对称的特征点是否**只取了一个**？
- [ ] 顺序规则是否明确说明（前→后 / 上→下 / 左→右 / 里→外）？
- [ ] 每个连接是否**直接接触**（不是"旁边有""看着"）？
- [ ] 是否**依次**放桩，没有一次放多个？
- [ ] 图像是否**立体**（没有 APP 图标、贴图案这类平面化）？
- [ ] 是否做到**夸张 / 动态 / 破坏**？
- [ ] 标题与桩物体的连接方式是否说明？
