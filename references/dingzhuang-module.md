# 模块定桩法

来源：第39课（找桩标准、桩子路径标准）、第40课（放桩标准、独立模块、实践）

课程定位：「**微观宏观定桩法的一个延伸版**」。

## 方法定义

> **若干单个物体组合在一起形成一个模块**，按一定顺序规则找出模块中的所有微观/宏观桩子，
> 称为**模块桩**。将所记信息提取关键词出图后依次放在模块桩上。
> 模块可以单独使用，也可以几个模块组合成一套有序模块使用。

## 与空间故事定桩法的关键区别

| | 模块定桩法 | 空间故事定桩法 |
|---|---|---|
| 找的是 | **模块**（几个物体的组合） | **区域**（一块地方） |
| 桩子 | 模块中所有物体的微观/宏观特征点（**叠加**） | 一个区域（放整个故事） |

> 课程原话：「这个地方我们找的是模块，然后空间故事定桩法找的是一个区域，**这是完全不一样的**。」

## 核心机制：桩子叠加

模块中的每个物体都按微观/宏观法找桩，**桩号连续累加**。

例（床头柜 + 台灯 + 相册 = 一个模块）：

| 物体 | 找桩 | 桩号 |
|---|---|---|
| 台灯 | 从最高处开始，找出 9 个 | 1～9 |
| 相框 | 从左边角开始，找出 6 个 | 10～15 |
| 柜子 | 继续找 | 16～22 |

→ **三个物体就得到 20 多个桩子。**

## 找桩技巧（5 条）

1. **如果有多个模块，各模块之间要有明显的界线**
   > 「每个模块它们之间都有接触，但是它们的区别很大，有很明显的一个界线。」
2. **模块中的图像尽量固定位置**；位置不固定的图像可以不加入模块
   > 例：枕头位置不固定，就不放进模块
3. **模块中的图像按「从上到下、从左到右、从前到后、从里到外」排序**；模块中的物体也要排序
4. **模块中图像的找桩方法按照微观/宏观定桩法的规定来寻找**
5. **同一个模块中不同图像上的桩子数量可以叠加**（这就是它的定义）

## 出图前置门槛（先过这一关）

> **通用铁律（见 SKILL.md「通用铁律」）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**。

放置前，每个图像必须先满足 **具体、独立、有大小**，否则无法放在桩上：

- **具体** —— 有明确样子（✗ 天空、平原、住所）
- **独立** —— 能单独成立（✗ 空瓶子、嘴唇）
- **有大小** —— 有体积才能放桩（✗ 国家、地区）

详见 `SKILL.md` 第 3 步。

## 放桩标准（6 条）

1. 图像与图像之间、图像与桩子之间要**直接接触**
2. **图像不能平面化**，连接不能平面化
   > 反例：玻璃上贴着老虎的图案
3. **装置上不能同时放多个图像**，要**依次**放桩
   > 反例：电脑屏幕上面老虎和狮子两个图像一起出现 → 无法区分顺序
4. 注意装置上图像的**先后顺序**
5. 图像连接需要**夸张化、动态化、有破坏性**
6. **将整个模块当成每一个桩子的背景**
   > 例：主机最上面是第一个桩，这个桩的背景就是**整个模块**；鼠标是一个桩，整个模块也是它的背景

## 独立模块桩（第40课，重要技巧）

有一类模块**不需要去现实中寻找，也不需要去记** —— 你凭常识就知道它们是一起的：

| 例子 |
|---|
| 鼠标、键盘、显示屏、主机 |
| 牙刷、牙膏、牙缸 |
| 烟、烟灰缸 |
| 扫帚、铲子、垃圾桶 |
| 大熊猫、竹子、竹笋 |
| 弓箭、靶子 |
| 手机、充电器、耳机 |

> 课程原话：「这些模块是**你自己已经记住的东西**，不需要再去找模块桩……
> 这个方法不需要你去找桩，不需要你去找模块，因为**你自己闭上眼睛就能够想得到**。」

**这是效率最高的桩子来源之一** —— 建议优先使用。

## 在哪里找模块

- **室内**：一个房间通常能找到 **4～5 个模块**
  例：床头柜+台灯+相册（模块1）；床+壁画+枕头+垫子（模块2）；窗户+窗帘（模块3）；暖气片+椅子（模块4）；柜子+柜上物品（模块5）
- **街道/室外**：一棵大树（模块1）；电线杆+红绿灯（模块2）；机箱+窗户（模块3）；窗户+两侧+上方（模块4）；摊位+椅子+台面（模块5）；围墙+栏杆（模块6）

## 交付检查清单

- [ ] 模块是否由**若干单个物体组合**而成？
- [ ] 各模块之间是否有**明显界线**？
- [ ] 模块内物体是否按固定顺序排序？位置不固定的是否已排除？
- [ ] 桩号是否**连续累加**（跨物体）？
- [ ] 是否说明了**整个模块作为背景**？
- [ ] 是否优先考虑了**独立模块**（常识性组合）来省去找桩成本？
- [ ] 放桩是否满足直接接触 / 非平面 / 依次 / 夸张动态破坏？
