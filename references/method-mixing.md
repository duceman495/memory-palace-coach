# 方法混用（高阶策略）

来源：第47课（方法混用）、第48-54课（短/长知识记忆实操）、第56课（思维导图记忆）

> 课程原话：「图像方法之间，就是每一个方法之间可不可以混着用、一起使用呢？**那肯定是可以的。**」

**这是本科目最高阶的策略** —— 桩子不够、材料太杂、单个方法啃不动时用。

# 通用铁律（所有方法都适用，见 SKILL.md）

> 图像必须**具体、独立、有大小**；**禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**、**依次**放置。

## 五种混用模式

### ① 影像故事法 + 图像转换定桩法

**用途**：先串标题，再用小标题的图像做转换图像。

**步骤**：
1. 提取标题关键词 + 各小标题关键词
2. **用影像故事法把"标题 + 小标题"串起来**（先记住骨架）
3. 再把小标题的**出图**作为**转换图像**，转换出装置，用来记小标题下面的内容

**案例**（「教室的职业道德规范」→ 教德）：
- 小标题：守法、敬业、关爱、育人、师表、学习
- 先串：教德 → 守法 → 敬业 → 关爱 → 育人 → 师表 → 学习
- 再转换：拿「手套」（守法出图）作转换图像记第一点；拿「镜子」（敬业）作转换图像记第二点……

### ② 宏观/微观定桩法 + 图像转换定桩法

**用途**：**桩子不够**时。

**步骤**：
1. 先用宏观/微观法在物体上找桩（如大象 → 13 个桩）
2. 关键词超过桩数时（如 20 个关键词，只记了 10 个）
3. **把整个物体本身作为转换图像**（即把它放进 `dingzhuang-transform.md` 的 10 条转换规则序列），再转换出一套装置，继续记剩下的内容

> 同一个图像可以用两次：**第一次当宏观桩物体，第二次当转换图像。**

**案例**：用大象记一个知识点，大象只找到 13 个桩 → 记完前几点后桩子用完
→ **把"大象"本身放进转换规则**，又得到一套装置 → 记剩下的内容

### ③ 标题联想定桩法 + 图像转换定桩法 + 影像故事法

**用途**：**增加单个桩子的承载量**。

**核心**：把"一个桩放 2～3 个关键词"提升到「**一个桩放 4～8 个关键词，即放一整个影像故事**」。

**案例**：
- 标题联想：科 → 蝌蚪（联想青蛙）→ 得到桩子
- 每个桩子**放一整个影像故事**（4～8 个关键词）
- 图像转换法同理：把一头犀牛转换出"单个犀牛 / 一群犀牛"等桩子，**每个桩放一整个影像故事**

### ④ 模块定桩法 + 图像转换定桩法

**用途**：模块桩记不完时，**把模块里的元素单独拿出来做转换图像**。

**案例**：
- 一个模块记了知识点前 3 个点，后面还有更多点
- → 把这个模块里的**桶**拿出来放进转换图像 → 又一套装置
- → 还不够？再把**亭子/站台**单独作转换图像 → 又一套装置

### ⑤ 微观/宏观定桩法 + 模块定桩法 + 空间故事定桩法

**用途**：在物体/模块上找**区域桩**而不是微观宏观桩。

**做法**：不找"桶盖上的角""桶身上的面"这类微观桩，而是**把整块地方当区域**：
- 整个桶盖 = 区域桩 1
- 整个桶身 = 区域桩 2

**案例**（站台）：整个顶部 = 区域 1；整个侧面 = 区域 2；整个里面 = 区域 3
→ 如果找微观宏观桩会得 7～8 个，**找区域桩只有 3 个**（因为一个区域放的是整个故事）

## 方法选择的决策树（长短知识实操总结）

来自第48-54课的实操案例，**同一知识点往往多种方法都可行**：

```
材料有标题 + 大小标题 + 多个分点
   │
   ├─ 分点数少（2～3 个）且有转换图像可用
   │    → 图像转换定桩法（标题每个字出一个转换图像，分别记一点）
   │
   ├─ 想要桩子多且快
   │    → 宏观/微观定桩法（找一个大的物体/动物，随便找出十几个桩）
   │
   ├─ 想要一个模块就搞定
   │    → 模块定桩法（一个模块 10～20 个桩）/ 独立模块桩
   │
   └─ 要按区域整体分配
        → 空间故事定桩法（标题放最突出图像，小标题+分点分配到区域桩）
```

**分配原则**（空间故事定桩法用于长知识时）：
> 「如果无法一次性把所有关键词放在一个区域桩里面，那么你可以**两个点放一个桩**。」
> 例：小标题+第1、2点 → 区域桩1；第3、4点 → 区域桩2；第5、6点 → 区域桩3
> → **3 个区域桩就能搞定一个长知识点**。

**重要提醒**：
> 「**单独某一个知识点并不一定只能用某一个方法来记忆，其他方法都可以。**」

## 思维导图材料

来源：第56课

**核心认知**：「这些思维导图**也都是书本上的知识点**，你把书本上的知识点迁移到思维导图里面去了。
所以说**记忆方式和书本上的知识点是一样的**。」

**流程**：
1. 找出标题
2. **一次性把所有大点、小点的关键词全部找出来**
3. 选方法（课程案例用空间故事定桩法：标题放最突出图像，各大点/小点分配到区域桩）
4. 若大点关键词多，可**一个大点单独占一个区域桩**

**电子档（XMind）的标注技巧**：
> 「如果思维导图是电子档，无法在上面标记关键词怎么办？
> 选中这一点 → 用它后面的**标注/引用**功能 → 会出现一个可输入文字的方框
> → 把关键词写在里面，**后面打两个点，把出图写在后面**。」

这样复习时**直接看电子档思维导图**即可（关键词和出图都在上面）。

**若某几点你已经能理解记住**：
> 「如果这三个点当中有两个点你能够记住，那么这两个点你可以不用提取关键词；
> 如果都能够记住，那这段话你就不用记了 —— **因为你自己理解的方式下已经记住了，就不用图像记忆法来记**。」

## 中文长文：套娃式分段记忆（第33课）

**用途**：超长文言文/文章，桩子用完了但内容还没完。

### 核心机制

> 将**前面一段的最后一句话**作为**后面一段的标题**。

```
第1句 → 出 8 个图 → 8 个桩 → 记后面 8 句
         ↓ 桩用完时
第1句到第8句的「最后一句话」→ 又出 8 个图 → 又 8 个桩 → 继续记
         ↓ 再用完
再取新一段的最后一句话 → 再套一层……
```

> 课程原话：「就像**套娃一样，一个套一个**。」

### 案例（《滕王阁序》）

| 步骤 | 做法 |
|---|---|
| 1 | 「豫章故郡，洪都新府」8 个字 → 出 8 个图 → 8 个桩 |
| 2 | 用这 8 个桩记后面 8 句（一句一桩） |
| 3 | 刚好记到「千里逢迎，高朋满座」—— **这句话就成为下一段的标题** |
| 4 | 「千里逢迎，高朋满座」8 字 → 又出 8 个图 → 又 8 个桩 |
| 5 | 继续记剩下的内容 |

**回忆路径**：回忆到「千里逢迎，高朋满座」这句时，就知道它同时是下一段的起点。

### 变体：背景可以不一样

> 「每一段话的标题就是它们的装置背景。**装置背景可以不一样。**」

例：第一段用鱼缸作背景；第二段可改用桌子作背景（因为第二段的标题是具体的物象）。

### 一句话一桩，还是两句一桩

| 配置 | 效果 |
|---|---|
| 一句话 = 一个桩 | 8 个桩能记 8 句 |
| 两句话 = 一个桩 | 8 个桩能记 16 句 |

按内容量自行选择。
