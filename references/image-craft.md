> 这节课解决：「我的图像感不强要怎么办？我记不住图像要怎么办？我的想象力不强要怎么办？」
> 课程原话：「你只要严格地按照技巧的方式来进行图像的记忆，那么你就可以实现**一遍记忆图像**。」

# 通用铁律（所有方法都适用，见 SKILL.md）

> 图像必须**具体、独立、有大小**；**禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**、**依次**放置。

## 一、五大图像创造技巧

### ① 夸张、奇特、大场面、充满破坏性

四个点**每一个都很重要**。

> ⚠️ 四个都要尽量做到，**不是选两个**。其中**破坏性**和**大场面**性价比最高，
> 优先把这两个做到（破坏产生细节；变大变多才能放到桩上）。

- **夸张** —— 在图像**本身的属性**上夸张（见下方"禁止拟人化夸张"）
- **奇特** —— 天马行空，违反常识
  > 「一个巨大的包子上面爬满了好多的蚕，这个画面现实中见不到，但你自己可以想象得出来」
- **大场面** —— 图像太小不方便连接和放装，就**变大或变多**
  > 贝壳太小 → 一堆贝壳 / 一个巨大的贝壳
  > 一头大象 → 一群大象（「一群大象的冲击力要比一头大象大得多」）
- **破坏性** —— **破坏就会产生细节，记住细节就记住了整个图像**
  > 锄头去挖白菜 → 白菜被挖成好几块
  > 蛋糕去炸豆腐 → 蛋糕炸成稀巴烂
  > 灯泡去炸钢盔 → 灯泡自己碎掉
  > 钢笔去炸钢盔 → 砸出一个一个的洞

> ⚠️ **禁止拟人化的夸张**：
> 「案板用手举着这辆车 —— 案板就没有手，它没有长出手出来。
> 如果你一定要想象案板长出手，你还要记住案板长出手的样子，这样会增加你的记忆难度。」
> **要夸张，但只能在图像本身的属性上面夸张。**

### ② 多想象图像与图像之间产生的细节

> 「有时候你不需要把整个图像全部想出来，也不需要想得多清晰、画面感多强，
> 你只需要把**图像与图像之间产生的细节**记下来，你就能够把图像记住。」

例：狮子和大象 → 只记「狮子撕咬大象屁股」这个**过程**，
狮子全身什么样子、大象全身什么样子，都不需要清晰记住。

**细节 = 动作留下的痕迹**：
- 鞭子去打锤子 → 锤子上留下印记 + 抽打那一瞬间
- 锤子砸案板 → 砸出一个洞 / 砸成两半 + 砸的那一瞬间

### ③ 加入主观感受，身临其境

「你自己加入到图像的连接过程当中。」

例：不是瞬间看到"西红柿上砸满牙签"，而是**你想象自己一根一根地把牙签砸上去**。

### ④ 动态影像连接

整个画面是动态的，像电影一样。

**图像有自身的动作**（按属性）：
| 图像 | 固有动作 |
|---|---|
| 鞭子 | 抽打 |
| 锤子 | 砸 |
| 案板 | 拍、砸 |
| 车 | 开过来、撞上去 |
| 苹果 | 从天上掉下来、扔过去砸 |
| 头发 | 随风飘起来 |
| 饼干 | 掰碎 |

**动作要符合图像的属性** —— 这是判断"夸张是否越界"的标尺。

### ⑤ 多感官参与（六项，不要求全用）

| 感官 | 例 |
|---|---|
| **视觉** | 颜色、轮廓、大小（最基础，其他都没有也能记住） |
| **听觉** | 砖头砸鸡，要"感觉"到鸡的叫声 |
| **味觉** | 吃西瓜，清甜、凉快 |
| **触觉** | 抱着榴莲的触感、弓箭射狮子时手的触感 |
| **嗅觉** | 榴莲的臭味 |
| **情绪** | 害怕狮子、兴奋惊喜 |

> **关键**：不要求全部想出来。「你可能就重点只是视觉的连接，然后增加一些像触觉、情绪这样的……
> **有视觉其他都没有也没有关系，你都能够记住图像**。」

## 二、快速出图的四条策略（第5课）

> **本 skill 内置了**《拼音图像库》（`assets/pinyin-image-library.md`，398 拼音/1134 图像）。
> 下面四条策略建立在“可以随时查表”的前提上。

### ① 熟记拼音图像库

**已内置**：[`assets/pinyin-image-library.md`](assets/pinyin-image-library.md)。

课程原话：「只需要熟悉几遍 + 一些关键词出图练习，你可以在极短的时间就能够瞬间出图。」

> 课程配套的**完整版**有近 400～500 个拼音；内置版本 398 个，基本完整。

### ② 出图不用写下来

「出的图像**不用写下来**，只在脑海里面出图。**会的快速过，不会的不熟悉的要查看拼音图像库并找出答案和记录**。」

### ③ 眼里只有拼音，四个声调挨个尝试

看到字 → 看拼音 → **四个声调挨个尝试** → 直到能准确说出某个声调的图像。

### ④ 出图图像名称的第一个字，尽量是原字的谐音

**这条是"容易还原"的关键**。

例：**知**道 → 出图 **蜘蛛**（蜘 zhī 谐音"知"）
→ 每次看到图像，都默认"图像名称的第一个字"是由原字转化来的
→ 还原时不用纠结「我当时是用'知'还原回去还是用'猪'还原回去」

**要求**：形象词的**第一个字**的拼音，要和被转化的字**拼音相同**。

## 三、三种出图练习方式

| 方式 | 是否写下来 | 目的 |
|---|---|---|
| **词汇出图** | **要**写在另一张纸上，再看着图像还原词汇 | 转化和还原练习 |
| **知识段落出图** | **不写**，逐字出图，会的直接过 | 提高速度和准确率 |
| **文章出图** | **不写**，同知识段落 | 提高速度和准确率 |

**错字本**：不会的、不熟悉的字 → 标注出来 / 集中写在一个本子上 → 把正确答案写在下面 → 日后复习
**目标**：「百分百能够瞬间出图」。

## 四、图像感知小课堂（第59-60课）

短课时的图像感专项训练。核心动作：**睁眼观察 → 闭眼回想细节**。

课程给的四点训练法（第9课也讲过）：
1. **睁眼观看事物后闭眼回想细节** —— 随时可做
2. **观看视频后闭眼回想整段视频** —— 借助刷视频的习惯，回想人物细节
3. **随意想象** —— 天马行空
4. **多进行方法的应用** ←「**最后一步非常重要**：你做好这一点，基本上前面这些都可以不用做」
   > 「你每用一次方法，你每训练一次，你的图像感、你的图像能力就会得到相应的提升。」

## 交付检查清单

- [ ] 图像是否同时做到**夸张 + 奇特 + 大场面 + 破坏性**（四项尽量齐，至少不能缺破坏性/大场面）？
- [ ] 夸张是否在**图像本身属性**内？（有没有越界成拟人）
- [ ] 是否写出了**图像之间的细节**（痕迹、瞬间），而不只是两个图像并置？
- [ ] 是否让用户**身临其境**参与？
- [ ] 动态是否**符合图像属性**？
- [ ] 小图像是否**变大或变多**？
- [ ] 出图时是否尽量满足"**图像名称第一个字 = 原字谐音**"（便于还原）？
- [ ] 有没有提醒用户建**错字本**？
