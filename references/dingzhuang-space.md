# 空间故事定桩法

> **通用铁律（所有方法都适用，见 SKILL.md）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；
> 图像之间必须**直接接触**、**依次**放置。

来源：第34课（找桩标准）、第35课（放桩标准）、第36-38课（实践记忆）

课程评价：「今天要讲的方法**非常特殊，而且非常非常的高效**……这是一个全新的方法。」

## 与其他定桩法的根本区别

| | 其他定桩法 | 空间故事定桩法 |
|---|---|---|
| 桩子 | 物体上的**单个特征点** | 一个**区域** |
| 放什么 | 1～3 个关键词 | **整个图像故事**（4～10 个关键词） |
| 数量 | 一个物体 6～15 个桩 | 一个房间 7 个区域；一条路线 15 个区域 |

> 课程原话：「之前学的定桩方法是放在桌子的某个角、自行车上的某个角，
> 但今天这个方法我们是**把整个图像故事放在一个区域里面**。」

## 方法定义

> 在**室内或开放地方**画出一系列**有序的区域**，注意划分边界，将整个图像故事依次放入区域桩。

桩子称为**区域桩** —— **几个图像结合在一起形成一个区域桩**。

## 区域桩的三种类型

| 类型 | 说明 | 例 |
|---|---|---|
| **① 几个图像结合成一个区域桩** | 相邻的多个物体合起来算一个区域 | 两幅画 + 瓶子 + 桌子 + 两张椅子 |
| **② 单个大型物体作为区域桩** | 物体足够大就单独算一个区域，把周边属于它的也囊括进去 | 沙发（包括它后面的画） |
| **③ 一整块区域作为区域桩** | 划定一块地板/空间，其上的所有图像都归入 | 一块地板上的坐垫、毯子、两张桌子上的东西 |

## 找桩技巧（6 条）

1. **区域不能太大** —— 要非常紧凑
2. **各区域之间的大小差异不能太大** —— 否则不好做对比、不好放桩
3. **区域之间的距离不能太远** —— 太远则不好连续连接，「从这个地方想到这个地方，你可能会把它们的联系忘掉」
4. **区域内的图像分布不能太单一** —— 但即使全是一模一样的（如教室桌椅、观众席凳子），也可以单独当成一个区域桩
5. **标题关键词放在区域中最突出的一个图像上面**（如门），并且**这个图像不加入任何一个区域** —— 它的唯一责任是记标题，让你知道这个知识点是用这个房间记的
6. **区域中第一个图像要放在最高或最突出的部位** —— 便于回忆

## 一个区域桩放多少关键词

**4 个以上**：4、5、6、7、8、10 个都可以。

> 课程建议：如果知识点有 7 个大点，每个大点有很多内容，
> 那么**一个大点单独放一个区域桩**。这样「记忆的清晰度非常强，深刻性非常强」。

## 在哪里找区域

- **室内**：一个房间通常能找出 **7 个区域**
  例：门+柜子+两堵墙+地板+屋顶 = 区域1；靠墙桌子+画+椅子 = 区域2；电视柜+电视 = 区域3；
  地上整块范围 = 区域4；沙发+后面的画 = 区域5；上方部位 = 区域6；下方+上方所有东西 = 区域7
- **室外**：更多。沿一条路走，
  例：一棵树 = 区域1；两排树中间 = 区域2；三角形范围 = 区域3；一片树林 = 区域4；
  光秃秃的地 = 区域5；棚子 = 区域6；草坪 = 区域7……
  **一个公园走一趟能得到 15 个区域**

## 应用技巧（第34课开头，与其他课一致的通用原则）

- 记忆材料尽量是**主题 + 内容**（有标题 + 内容），不要记零散资料
- **能一遍理解记下来的部分，就不用提取关键词** —— 只有"不好记的这部分"才提取关键词
- 左右脑结合，发挥各自长处：「这种技法加强巩固，才能实现高效记忆的目的」

## 交付检查清单

- [ ] 区域划分是否给出了**边界**（明确哪几样东西属于这个区域）？
- [ ] 区域是否**紧凑**、大小差异不过大、间距不过远？
- [ ] 每个区域是否放了 **4 个以上**关键词？
- [ ] **标题图像**是否放在最突出的图像上且**不参与任何区域**？
- [ ] 区域中第一个图像是否在**最高/最突出**部位？
- [ ] 是否说明了场景（室内哪个房间 / 室外哪条路线）？
