# 影像故事法（基础方法）

> **通用铁律（所有方法都适用，见 SKILL.md）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；
> 图像之间必须**直接接触**、**依次**放置。

来源：第6课（方法标准、故事背景）、第7-8课（两种故事类型）、第9课（图像顺序判断标准）

这是整套课程的第一个方法，也是**最基础的方法** —— 它训练"图像之间的连接能力"，后续所有定桩法都要用到这个能力。

## 方法定义

把关键词出的图像**连接成一段影像**，像看电影、看动画片一样的视频画面。

## 七条标准

### 标准 1：确定影像故事背景

故事必须有背景。三种确定方式，任选其一：

| 方式 | 做法 | 例 |
|---|---|---|
| **① 第一个图像作背景** | 把第一个图像**变大或变多**当背景 | 粉笔太小 → 变成金箍棒一样大 / 地上一堆粉笔铺满 |
| **② 关键词或关键词组的联想场景作背景** | 从第一个图像联想出一个场景；第一个想不出就用第二个；关键词组的**任一图像**都可以 | 榴莲 → 榴莲树；梨/戒指 → 梨树 / 戒指专柜 |
| **③ 选定现实中任意场景** | 自己的床、卧室、厕所等 | 直接拿来当背景 |

**关键**：后续所有图像都要在这个背景上连接。课程强调「一定要想象出那个背景出来」。

### 标准 2：图像之间范围不能太大

两个图像必须**紧凑连接，距离不能太远**。

原因：人脑有**图像空间**限制 —— 只能在这个空间内完整看清画面。距离太远就只能看清一部分。

- ✗ 差：「粉笔在这一端，大象在一千米开外」
- ✓ 好：「粉笔直接堆在大树下面，大象过来吃这个树叶」

### 标准 3：图像之间必须直接接触

**这是最重要的一条。** 「位置」和「看见」都是错误方式。

- ✗ 差：「大树前面有一头大象」「大象看着大树」「书本在大象屁股后面」
- ✓ 好：粉笔**扔在**树上、大象**吃**树叶、书本**背在**大象背上、用伞**去接**蘑菇

### 标准 4：连接要流畅，图像原有状态不能改变

不能瞬间切换状态，中间必须有**可见的连接过程**。

- ✗ 差：大象在吃树 → 瞬间变成在大吞书本
- ✓ 好：大象吃完树叶后**缓慢转过身体**，看到书本，用鼻子**卷起**书本塞进嘴里

原因：影像故事要流畅，像看电影一样，不能突然切换画面。

### 标准 5：主观感觉参与连接（身临其境）

想象**你自己**参与故事。

例：「想象你自己拿着书本去喂这头大象；书本上长出了蘑菇，你用手把蘑菇摘下来放进雨伞里」。

### 标准 6：完全图像化连接，不允许"拟人"和"非图像故事"

| 禁止 | 含义 | 反例 |
|---|---|---|
| **拟人** | 无生命物体做它不能做的动作 | 「书本跑起来去吃蘑菇」（书本没手没脚） |
| **非图像故事** | 不是图像的描述 | 「大象恐惧地看着书本」「大象慢悠悠地看书」 |

> 例外：图像感很强的人才可以少量拟人 —— 因为想象「蘑菇长出手」本身增加了记忆难度。

#### 特例：「看 / 听 / 想」这类词本身就是要记的内容时怎么办

上面禁止的「看着」是指**用“看”来替代两个图像之间本该有的连接动作**（偷懒）。
但当**词义本身就是“看/听/想”**时（如英语单词 stare 凝视、watch 观看；或知识点里的「观察」「注视」），
“看”不是偷懒，而是**要记的目标本身**。此时不能直接写「A 看着 B」，而要把这个动作
**转成可见的物理效果**：

- ✗ 差：「鹅在抬头凝视着星星」（无法画出“凝视”，违反标准 3）
- ✓ 好：「星星黏在鹅的蚤珠上，鹅蚤珠凸得快爆了、死死盯住它，星星被盯得冒烟」

常用转法：**蚤珠凸出 / 目光烧穿 / 把对方盯得冒烟、变形、融化 / 身体前倾到鼻子撞上去**。

> 一句话原则：**“看”要看得见。** 实在转不出来，就加一个物理接触作为锚点，
> 让“看”只是附带的情绪，而接触承担顺序判断。

### 标准 7：不能同时连接多个图像

必须**依次连接**。同时连接会导致顺序无法确定。

- ✗ 差：「大象的背上有书本和蘑菇」（两者顺序不明）
- ✓ 好：粉笔→大树→大象→书本→蘑菇→雨伞，一个一个接

## 关键词内部组合技巧（重要）

**同一个词汇的多个图像要先组合，再和外部连接。** 这样便于还原词汇。

例：「牙签」+「麻雀」→ 先组合成「牙签串着麻雀」，再去被点燃的坦克上烤。

原理（第9课）：一个词汇有几个字就出几个图。如果不先组合，回忆时会**平均分配图像** —— 三个字的词只回忆出两个图就还原不回去。

组合时也要用下面的顺序标准确定内部先后。

## 图像顺序判断标准（6 种）

连接完之后要判断哪个图像在前，用以下标准：

| 标准 | 说明 | 例 |
|---|---|---|
| **① 时间顺序** | 随时间流逝依次出现 | 麻雀先飞过来 → 才抓住钉子 |
| **② 位置关系（上下）** | 上面的图像在前 | 琴顶在猩猩头上 → 琴是第一个 |
| **③ 位置关系（左右）** | 左边的图像在前 | 大猩猩在右边弹琴 → 左边的琴是第一个 |
| **④ 主动 / 被动** | 主动连接的图像在前 | 麻雀去抓钉子 → 麻雀在前 |
| **⑤ 外和内** | 外面的图像在前 | 杯子里面装戒指 → 杯子是第一个 |
| **⑥ 前后关系** | 前面的图像在前 | 麻雀在钉子前方 → 麻雀在前 |

**用这套标准连接，回想时就不会混淆顺序。**

## 长影像故事法（第10课）

大量知识记忆策略：把多个影像故事串成更长的故事。用于条目超出单组故事容量时。

## 交付检查清单

生成影像故事时，逐条自检：

- [ ] 有没有明确背景？
- [ ] 图像之间是否紧凑（范围不大）？
- [ ] 每一对相邻图像是否**直接接触**？
- [ ] 连接过程是否流畅、有无状态突变？
- [ ] 是否让用户**自己参与**了？
- [ ] 有没有拟人 / 非图像描述？
- [ ] 是否**依次**连接，没有同时连接多个？
- [ ] 同一词汇的多个图像是否先组合？
- [ ] 顺序能否用 6 种标准之一判断出来？
