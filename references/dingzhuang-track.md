# 轨迹定桩法（最后一个方法）

来源：第61课（轨迹定桩法）、第62课（轨迹定桩法案例实训）

课程定位：「**我们来讲解最后一个方法**。这个方法非常特别。」

# 通用铁律（所有方法都适用，见 SKILL.md）

> 图像必须**具体、独立、有大小**；**禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**、**依次**放置。

## 方法定义

> 将一系列**有序的位置或物体圈出来，不分大小**，按**线性方向**排序，形成一套有序的轨迹装置。

**关键突破**：这是**唯一不限制桩子大小**的方法。房子、山、竹林、水面、天际线都能当桩子。

## 核心特征

| 特征 | 说明 |
|---|---|
| **不分大小** | 「这副桩子是不是多离谱，这几栋房子怎么可以当成一个桩子，但是可以，在这个方法里面是可以的」 |
| **必须线性** | 「不是一个圆，也不是随便的，是一个**线性方向**。只要是不闭合的一条线就行」 |
| **桩子数量无限制** | 「装置内心没有限制，找桩更加自由」 |
| **可以从网上下载图片** | 「轨迹桩是可以从网上面去下载，网上下载很多的图片来进行找桩，**自己可以不用到现实当中去找**」 |

## 三大用途

1. **画面单一的场景也可以找桩** —— 突破找桩限制和桩子的限制
2. **临场记忆** —— 「环顾四周就能够找到桩子」
   - **演讲、主持**等需要临场记顺序的场景，这是首选方法
3. **应用范围广** —— 工作、学习、生活场景均可

## 找桩方法：随便画一条线

**这是最核心的操作**：在图片或实景上**任意画一条线性路径**，沿线经过的物体就是桩子。

示例（一张庭院图，画一条线）：
树 → 台灯 → 台阶 → 草坪 → 小路 → 白色油路 → 草地 → 水面 → 一片区域 → 天际线/房子
→ **10 个桩子**

示例（一堆乱糟糟的建筑图）：
屋顶顶部 → 墙角 → 一块区域 → 另一个角 → 一块区域 → 柱子 → 白墙 → 铁栅栏
→ **8 个桩子**（「你看它是线性分布的，任何一个区域、任何一个地方都可以找出一套桩子出来」）

## 桩子大小与承载量成正比

**这是本方法的独特优势**：桩子越大，能放的图像越多。

| 桩子 | 可放图像数 |
|---|---|
| 一片竹林 | **十多个** 关键词 |
| 一块石头 | 4 个 |
| 一片区域 | 6～7 个 |

> 「放着图像数量可能也不一样……**它的放的图像的数量你可以自己分配**，怎么好放怎么来。」

**图像可以变大**：
- 「两双巨大的筷子插在这座山上」→ 小图像放大就能放到大桩子上
- 「一只巨大的像怪树一样的狮子蹲在这片竹林上面，把竹林都压塌了」→ 狮子变大

## 与其他方法的关系

轨迹定桩法和空间故事定桩法都涉及"区域"，但不同：

| | 轨迹定桩法 | 空间故事定桩法 |
|---|---|---|
| 排序依据 | **线性路径**（一条不闭合的线） | 有序区域的自然顺序 |
| 大小限制 | **完全不限** | 区域不能太大、不能太远 |
| 桩子性质 | 位置 **或** 物体都可以 | 区域 |
| 典型场景 | 临场、图片、演讲 | 固定空间（房间、路线） |

## 交付检查清单

- [ ] 路径是否**线性且不闭合**？（不能用圆或环形）
- [ ] 桩子顺序是否沿着路径明确说出？
- [ ] 是否体现了"**不分大小**"的优势（大桩子放更多图像）？
- [ ] 桩子较大时，图像是否**变大或变多**以匹配？
- [ ] 每个桩子上的图像数量是否按桩子大小**灵活分配**（不要求平均）？
