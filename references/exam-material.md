# 应试材料速记（文言文 / 选择题 / 表格）

来源：第55课（文言文记忆）、第57课（选择题多选题速记）、第58课（表格速记）

这三类是考试中最常见的特殊材料形态。它们的共同点是：**都要先"改造成标准知识点"，再套用已有方法。**

# 通用铁律（所有方法都适用，见 SKILL.md）

> 图像必须**具体、独立、有大小**；**禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；图像之间必须**直接接触**、**依次**放置。

---

## 一、文言文 / 古诗文

### 核心思路

**先理解译文，再提取关键词。** 课程反复强调这一点：

> 「你先理解译文之后再去提取第一个字，因为你译文只要理解一两遍就能够把整句诗给背下来。
> 但是**背诵最难的一个问题是前后内容的连接** —— 第一句和第二句的连接、第二句和第三句的连接。」

**图像记忆法在古诗文里的真正作用是解决"句子之间的连接"，而不是解决"单句记不住"。**

### 提取粒度：一句话一个词/字

| 材料难度 | 提取粒度 |
|---|---|
| 简短、画面感强 | **每句提取第一个字**（靠译文理解就能补全） |
| 稍难 | 每句提取**前两个字** |
| 难（如《归去来兮辞》） | 每句提取**一个词汇** |
| 整篇分段 | **以句号/问号/感叹号/分号划分**，逐段提取 |

> 课程原话：「每一句话你通过译文的理解，是能够很快背下来的……你提取一个字，
> 你可能通过译文的理解回忆的时候就能够回忆出来。」

**能提取一个字还原回去就提取一个字**，不要贪多。

### 可用方法（四种都行，按材料长短选）

| 方法 | 适用 |
|---|---|
| **影像故事法** | 画面感强的诗句 —— **把诗句描写的画面无缝衔接起来**，像一段影像 |
| **微观/宏观定桩法** | 一个词一个桩，标题与某个词合放一个桩 |
| **标题联想定桩法** | 标题每个字出图作桩 |
| **图像转换定桩法 / 空间故事定桩法** | **字数多、内容复杂的长篇**（如《归去来兮辞》、整篇《弟子规》） |

> 课程建议：「**不建议使用图像连接法（即影像故事法）还有标题定桩法**（对于长篇），因为它的关键词有点多，
> 用这些方法会相对来说有点复杂。**模块定桩法、空间故事定桩法、图像转换定桩法是天生就可以
> 用来记字数比较多、比较复杂的知识点。**」

### 分段记长篇（关键技巧）

> 「你可以将整个《弟子规》**拆分成很多段**，然后都用图像故事记忆。」

长文 = 多个短段 × 各自选方法。**不要试图一次记完一整篇。**

### 交付检查清单

- [ ] 是否**先请用户确认理解了译文**再开始编码？
- [ ] 是否说明了"图像法主要解决**句子之间的连接**"？
- [ ] 提取粒度是否**尽可能小**（优先逐句首字/首词）？
- [ ] 长篇是否**分段处理**，而不是一次记完？
- [ ] 是否避开了不适合长篇的方法（影像故事法、标题定桩法）？

## 二、选择题 / 多选题

### 核心思路：**标题关键词 + 答案关键词 → 合成一个影像故事**

> 「我们要在标题里面找出一个关键词出来……然后和**答案的关键词**出图，
> 把它们**串联成一个影像故事**。」

**这是唯一需要同时编码"题干"和"选项"的方法** —— 因为选择题的考点恰恰是"哪个选项对应哪个题干"。

### 步骤

1. **从题干中提取关键词**（通常取 2 个字，如「矛盾是事物发展的动力」→ 矛、动）
   - 若题干较长，取**核心词 + 辅助字**
2. **从正确选项中提取关键词**（如答案 D「矛盾的同一性和斗争性相结合」→ 同、斗）
3. **两组图像合成一个影像故事**

### 案例拆解

**例 1（单选）**：矛盾是事物发展的动力 → 正确答案 D
- 题干关键词：**矛** + **动**（冬瓜）
- 答案关键词：**同** + **斗**（豆子）
- 编码：**毛（矛）插在冬瓜上，把它甩进一个装满豆子（斗）的桶里**

**例 2（单选）**：货币的基本职能 → A 价值尺度
- 题干：**货** + **值**
- 答案：**价** + **值**
- 合成一个影像故事

**例 3（多选）**：生产商品的劳动二重性 → CD 具体劳动、抽象劳动
- 题干关键词：**二** → 耳机；**重** → 虫子
- 答案关键词：**具** → 橘子；**抽** → 臭豆腐
- 编码：**耳机上趴着一只虫子 → 虫子掉到肩膀上的橘子上 → 橘子下面压着臭豆腐 → 拿起臭豆腐推进肚子**

**例 4（多选）**：生产资料包括 → BD 劳动工具、原料
- 题干：**生**（花生）+ **资**（紫菜）
- 答案：**工**（蜈蚣）+ **原**（圆规）
- 编码：**一盘花生上面长出紫菜 → 一只蜈蚣爬进紫菜里吃花生 → 你拿圆规去扎蜈蚣**

**例 5（多选）**：产业资本的三种职能形式 → C 货币资本、生产资本、商品资本
- 题干：**产** + **资** + **三**
- 答案：**货** + **生** + **商**

### 为什么这样有效

编码后，**看到题干图像就能同时想起答案图像** —— 直接解决了"选项混淆"这个选择题的头号问题。

### 交付检查清单

- [ ] 是否**题干和答案都做了编码**（不能只编题干）？
- [ ] 多选题是否把**每个选项关键词**都编进同一个故事？
- [ ] 故事是否能让用户从题干图像**唯一地**推出答案图像？
- [ ] 是否只用了**直接接触**的连接动作？

## 三、表格速记

### 核心思路：**把表格"展开"成常规知识点**

> 「其实也很简单，**把它转化成我们常规的知识点**。表格的标题就是知识点的标题。
> 表格当中有几个点，就……」

### 转换步骤

1. **表格标题 → 知识点标题**
   例：「秦汉时期四大经典」→ 标题关键词 **秦汉四**（或 **秦四**）
2. **表格的每一行 → 一个分点**
   一行里的各列（如"作者/成书时期/影响"）**合并进这一个分点**
3. **每一行提取一个关键词组**
4. **选桩子方法**，逐行放桩

### 案例

**表格**：秦汉时期四大经典（列：著作 / 成书时期 / 作者 / 影响）

| 行 | 著作 | 合并后的分点关键词 |
|---|---|---|
| 1 | 黄帝内经 | 皇帝 + **战**（战国） |
| 2 | 难经 | 南 + **西**（西汉）+ 扁鹊（秦越人）+ 脉/经/命门/三焦 |
| 3 | 伤寒杂病论 | 伤 + 汉 + 张仲景 |
| 4 | 神农本草经 | 神农 + **十七**（十七卷） |

**选桩**：自行车（宏观桩）→ 找出 6 个以上桩（车把手、车篮、车座、后轮、前轮、后座架……）
→ 1 个桩放标题 + 4 个桩放 4 行，够用。

**放桩示范**（桩序：车把手 → 车篮 → 车座 → 后轮 → 前轮……）：

- **桩 1（车把手）—— 标题「秦汉四」**：**琴（秦）+ 汉堡（汉）+ 丝瓜（四）**
  → 一把琴卡在两个车把手之间，琴上堆着汉堡，汉堡上插着一根丝瓜
- **桩 2（车篮）—— 第 1 行「黄帝内经」（战国）**：**皇帝** + 辅助字 **战**（战术板）
  → 车篮里坐着一个拿着战术板的皇帝，战术板一下下拍在车篮铁边上，把车篮拍凹了
- **桩 3（车座）—— 第 2 行「难经」（西汉·扁鹊）**：**南（南瓜）+ 西（犀牛）+ 扁（扁担）+ 雀（麻雀）**
  → 南瓜压在车座上，南瓜里钻出一头犀牛，犀牛背上横着扁担，扁担上落着麻雀，麻雀一啄把南瓜啄裂
- **桩 4（后轮）—— 第 3 行「伤寒杂病论」（东汉·张仲景）**：**伤（绷带）+ 汉（汗水）+ 张（弓）+ 钟（大钟）+ 景（井）**
  → 后轮缠满绷带，绷带被汗水浇透；前轮上钉着一把拉满的弓，弓弦挂着一口大钟，钟口朝下露出一口井
- **桩 5（后）—— 第 4 行「神农本草经」（东汉·十七卷）**：**神农（戴草帽的农民）+ 十七（石头 + 旗子）**
  → 后座架上蹲着一个戴草帽的农民，双手握着草药；草根上绑着石头，石头上插着一面旗子

> **只要桩子数 ≥ 要记的行数即可**，多出来的桩子不用硬塞。
> 行数很多时（>15），改用模块定桩法或空间故事定桩法。

### 关键点

- **表格的"列"不单独出图**，而是**并进该行的分点里**（因为一行的列共同描述同一个事物）
- 桩子数 ≥ 行数即可，**行数多时可用空间故事定桩法或模块定桩法**

### 交付检查清单

- [ ] 是否把表格**转换成了"标题 + 若干分点"**的结构，而不是逐格编码？
- [ ] 是否**每一行合并成一个分点**（列不单独出图）？
- [ ] 桩子数量是否足够覆盖所有行？
- [ ] 是否说明了"表格记忆方式与常规知识点相同"？
