# 逐字精确类材料（法条 / 简答题 / 名词解释 / 流程步骤）

来源：综合第2-3课（信息简化）、第12-13课（定桩法与放桩标准）、第18课（图像转换）、
第48-54课（长短知识实操）、第55课（文言文精确提取）

> **通用铁律（所有方法都适用，见 SKILL.md）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；
> 图像之间必须**直接接触**、**依次**放置。
>
> 唯一例外：**图像感很强**的用户可以少量拟人（见 `SKILL.md` 「通用铁律」）。图像感弱/默认一律禁止。

这四类材料的共同特征：**不可改写、顺序严格、还原要逐字对得上**。
它们比普通考点更"脆"——少一个字就是错，所以提取策略要**偏保守**。

## 一、法条 / 条文

### 难点在哪

| 难点 | 后果 |
|---|---|
| **必须逐字精确**（「应当」写成「必须」就是错） | 不能靠"理解还原"省字 |
| **句式高度重复**（"依照…""应当…""不得…"反复出现） | 极易串条 |
| **条款号本身要记**（第 54 条 / 第 55 条） | 需要数字编码 |
| **相邻条款只差一两个字**（「维护」vs「保卫」） | 最危险的地方 |

### 策略：提取粒度往"密"走

普通材料可以用"记忆线索"（只提核心词），**法条不要**。因为法条的每个限定词都可能是考点。

| 材料 | 提取粒度 |
|---|---|
| 普通考点 | 记忆线索（能省则省） |
| **法条** | **关键词组为主，辅助字宁多勿少**；关键动词/限定词必须出图 |

> ⚠️ **对法条而言，SKILL.md 第 2 步"辅助字不出图"的例外要收紧使用**。
> 判据仍是"能否靠标题 + 理解补回来"，但对法条要**从严**：
> 只要这个词**可能与其他条款混淆**（如「维护」/「保卫」、「应当」/「可以」），就必须出图。

### 条款号怎么记

**用数字编码**（见 `bianma.md`）把条款号编码成图像，**接在该条故事的最前面**。

例：第 54 条 → 54 编码成图像 → 放在故事开头
→ 回忆时先出条款号图像，再进内容，**条号与内容不会脱钩**。

### 相邻条款防串

**给同一主题的相邻条款用不同的"桩物体"或不同的"背景"**，让它们在视觉上就分开。

> 原理同 `dingzhuang-title.md` 的"桩子背景"：**背景不同 → 不易混淆**。

### 交付检查清单

- [ ] 是否确认了**逐字精确**的要求（而不是按大意编码）？
- [ ] **关键动词/限定词**（应当/可以/不得/必须）是否都出图了？
- [ ] 条款号是否用数字编码接在故事前？
- [ ] 相邻条款是否用了**不同桩物体或背景**防串？
- [ ] 是否提示用户：**编码后仍需对照原文逐字校验**？

## 二、简答题 / 主观题

### 难点

- **要点数量固定**（少答一点就扣分）→ 需要"数量校验"
- **要点之间往往无逻辑顺序** → 适合影像故事法或定桩法
- **每点内部还要展开** → 需要"两层级"结构

### 策略：两层结构

```
第一层：要点数量 + 各要点的首字（用影像故事法串，解决"不漏点"）
第二层：每个要点的展开内容（分配桩子，解决"每点写得出"）
```

### 步骤

1. **先数要点数**，并把这个数字变成校验点（用数字编码）
2. **每点提取一个关键词组**，用**影像故事法**把各点首字串成一串（保证不漏点）
3. 若某点内部内容多 → **该点单独分配桩子**（用图像转换/宏观桩子/区域桩）
4. 桩子不够 → 见 `method-mixing.md`（把桩物体本身再作转换图像）

### 要点与桩子的对齐

课程实操里的分配原则（第52-55课）：

| 情况 | 分配方式 |
|---|---|
| 小标题 + 第 1、2 点 | 一个区域桩 |
| 第 3、4 点 | 一个区域桩 |
| 第 5、6 点 | 一个区域桩 |
| 某点内容特别多 | **该点单独占一个桩** |

> 「如果无法一次性把所有关键词放在一个区域桩里面，那么你可以**两个点放一个桩**。」

### 交付检查清单

- [ ] 是否**先数了要点数**并做成校验点？
- [ ] 是否有一条"骨架故事"保证**不漏点**（各点首字串起来）？
- [ ] 每个要点的**展开内容**是否分配了桩子？
- [ ] 桩子数与要点数**不匹配时**是否说明了分配方式？

## 三、名词解释 / 术语

### 难点

术语通常是一个**复合词**（如「机会成本」「边际效用」「资本有机构成」），
要记住的是**这个词本身 + 它的定义**。

### 策略

**第一步：拆词出图**（用 SKILL.md 第 3 步的三种方法）
- 整体谐音 → 拆合 → 联想
- 长术语用**核心词 + 辅助字**（`SKILL.md` 铁律三）

**第二步：定义用"关键词组 + 理解"还原**
定义通常有逻辑（"是指…"），**不需要逐字出图**，提取 1～2 个核心词即可。

**第三步：把"词"和"定义关键词"连成一个影像故事或放到桩上**

### 交付检查清单

- [ ] 术语本身是否**拆词出图**（而不是整词硬谐音）？
- [ ] 定义是否**只提核心词**（没有逐字出图，避免浪费）？
- [ ] 词与定义之间是否有明确连接？

## 四、流程性 / 操作性材料（流程、步骤、操作规程）

来源：第48-54课的实操思路可外推

### 难点

- **顺序严格**（步骤不能乱）
- **每步是动作型**（"打开…""加入…""加热至…"）
- **常带数值**（温度、时长、用量）

### 策略：桩子顺序天然对应步骤顺序

**这是最适合定桩法的一类材料** —— 因为桩子的顺序本来就是固定的，
直接**把第 N 步放到第 N 个桩上**，步骤顺序自动解决。

1. **选一个桩物体**（宏观/微观/模块/轨迹均可，桩数 ≥ 步数）
2. **按顺序放桩**：第 1 步 → 第 1 桩，第 2 步 → 第 2 桩……
3. **动作型步骤用"图像 + 动作"直接表达**（动作本身就是连接）
4. **数值用数字编码**接在该步图像上（见 `bianma.md`）

> 若步骤数很多（>15），优先用**模块定桩法**（一个模块 10～20 桩）或
> **轨迹定桩法**（不限大小，甚至可用图片找桩）。

### 完整示范（法条）

材料：《宪法》第 54 条
> 中华人民共和国公民有维护祖国的安全、荣誉和利益的义务，不得有危害祖国的安全、荣誉和利益的行为。

**判断**：法条天然“好懂但难逐字”，**不适用第 0 步“能理解就不编码”的豁免**。

**标题 + 条款号**
- 标题关键词：**宪法**（宪→线团，法→发卡）
- 条款号 **54** → 用数字编码接在故事最前面（5→钩子 / 4→旗子这类谐音）。
  ⚠️ **课程标准数字编码表不在本 skill 内**：若你没有该表，自己固定一个编码并**写进错字本**，
  一旦固定就不再改。**不要声称它是课程标准编码。**

**小段 1：…有维护祖国的安全、荣誉和利益的义务**
- 必出图的关键限定词：**维护**（围巾）、**义务**（椅子 + 雾）← 法条从严，不得省略
- 并列核心词：**安全**（马鞍 + 拳头）、**荣誉**（绒帽 + 鱼）、**利益**（梨 + 衣服）
- 可不出图：「中华人民共和国公民有」—— 宪法各条主体完全相同，不与其他条混淆
- 编码（背景：一张巨大的宪法书页铺成的地面）：
  围巾铺满整页宪法纸 → 你亲手把马鞍重重砸在围巾上，鞍面上压着拳头，马鞍被砸裂
  → 裂口里钻出绒帽，帽檐上挂着一条甩水的鱼
  → 你把梨硬塞进衣服里，衣服被撑破、梨汁渗出
  → 破衣服旁立着一把椅子，椅子上糊着厚厚一层雾，雾在往下滴水

**小段 2：不得有危害…的行为**
- 必出图：**不得**（布 + 德国国旗）、**危害**（桅杆 + 海马）、**行为**（刑具 + 胃）
- **同一组三词沿用小段 1 的图像**，但状态改成“被破坏”——既是“禁止”语义，也与小段 1 视觉分开
- **背景必须换**（改用考场大门、雨天）→ 防止两条串在一起
- 编码：大门口堵着一块布，布上裹着德国国旗 → 一根桅杆叉着海马冲过来
  → 桅杆把马鞍砸成两半，拳头散落一地 → 海马一口咬烂绒帽上的鱼
  → 破衣服被撕开，梨滚出来被踩得稀烂 → 一件刑具插进胃里，胃被戳破

**必备校验**：编码后**对照原文逐字读一遍** —— 重点查「维护」没写成「保卫」、
「不得」没漏、句尾是「义务」和「行为」。这才是法条还原的最终判据。

### 交付检查清单

- [ ] 桩子数是否 ≥ 步骤数？
- [ ] 是否**明确按顺序对应**（第 N 步 → 第 N 桩）？
- [ ] 动作型步骤是否用**图像 + 动作**表达？
- [ ] 数值是否用数字编码？

## 通用：逐字精确类材料的三条额外规则

1. **校验要用原文，不能只靠回忆**
   编码完成后，**必须对照原文逐字读一遍**，检查是否有字漏掉或替换。
   课程反复强调"还原"是最终判据 —— 对法条尤其如此。

2. **宁密勿疏**
   普通材料"能提取一个就绝不提取两个"；**逐字精确类材料以"能不能还原"优先**。
   详见 `SKILL.md` 铁律二的优先级规则。

3. **高频易混词单独建表**
   如「应当/可以/必须/不得」这类法条高频词，**为每个词固定一个专属图像**，
   一旦固定就不要再改（同数字编码的稳定性要求）。
