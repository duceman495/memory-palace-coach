# 英语单词速记

> **通用铁律（所有方法都适用，见 SKILL.md）**：图像必须**具体、独立、有大小**；
> **禁止拟人**（无生命物做它不能做的动作）与**非图像故事**（情节描述）；
> 图像之间必须**直接接触**、**依次**放置。

来源：先导课二（英语板块）

课程原话：「英语其实比汉语要简单很多 —— 英语单词无非就是从 A 到 Z 的 26 个字母组合成的，
所以关键在于**如何把这 26 个英文字母转化成图像**。」

## 三步流程

```
① 拆解单词  →  ② 将拆解后的内容编码出图  →  ③ 将编码出的内容和单词的意思进行连接
```

**第 ③ 步是关键**：不能只出图不造句 —— 必须把「拆解出的图像」和「单词本身的汉语意思」用一句话连起来。

## 六种拆分依据

### ① 熟词法
单词里含有你已认识的熟词。

- **smother**（窒息）= **s**（蛇）+ **mother**（妈妈）
  → 一条蛇把妈妈勒到窒息
- **seafood**（海鲜）= **sea**（海）+ **food**（食物）
  → 海里面的食物就是海鲜

### ② 象形编码法
字母形状像某个东西。

| 字母 | 象形 |
|---|---|
| S | 蛇 |
| H | 凳子 / 椅子 |
| C | 一轮弯月 |

- **clay**（泥土）= **c**（弯月）+ **lay**（谐音"累"→躺）
  → 月亮躺在泥土当中

### ③ 词根词缀法
拆分前先看有没有认识的词根词缀。

- **review**（复习）= **re**（再次）+ **view**（看）
  → 再次查看就是复习

### ④ 谐音法
整词或部分谐音成中文短语。

- **paste**（害虫）→ 谐音「拍死它」→ 害虫需要赶紧拍死
- **lay**（躺）→ 谐音「累」→ 累的时候就想找地方躺下

### ⑤ 拼音法
把字母组合读成汉语拼音。

- **si** = 四｜**e** = 鹅｜**ge** = 歌｜**gr** = 工人｜**ey** = 鳄鱼

- **seed** = **si**（四）+ **e**（鹅）+ **ge**（歌）
  → 四只鹅在围攻唱歌

### ⑥ 整体谐音法
整个单词谐音成一句中文。

- **ambulance**（救护车）→ 谐音「**俺不能死**」
  → 「俺不能死，快叫救护车救我」

## 完整示例

| 单词 | 释义 | 拆分 | 造句（第③步） |
|---|---|---|---|
| **chess** | 国际象棋 | **che**（车）+ **ss**（两条蛇） | 车里有两条蛇在下国际象棋 |
| **smother** | 窒息 | **s**（蛇）+ **mother**（妈妈） | 一条蛇把妈妈勒到窒息 |
| **seafood** | 海鲜 | **sea**（海）+ **food**（食物） | 海里面的食物叫海鲜 |
| **clay** | 泥土 | **c**（弯月）+ **lay**（累→躺） | 月亮躺在泥土当中 |
| **review** | 复习 | **re**（再次）+ **view**（看） | 再次查看就是复习 |
| **paste** | 害虫 | 整体谐音「拍死它」 | 害虫需要赶紧拍死 |
| **grey** | 灰色的 | **gr**（工人）+ **ey**（鳄鱼） | 灰色的工人吃了鳄鱼 |
| **mustache** | 胡子 | **mouse**（老鼠）+ **ta**（他）+ **che**（扯） | 老鼠在扯他的胡子 |
| **stare** | 凝视 | **star**（星星）+ **e**（鹅） | 鹅在抬头凝视着星星 |
| **seed** | 围攻 | **si**（四）+ **e**（鹅）+ **ge**（歌） | 四只鹅在围攻唱歌 |

> 注意 **grey** 的造句有多个变体都可以：「灰色的工人吃了鳄鱼」「工人吃了灰色的鳄鱼」
> 「工人吃了鳄鱼之后变成了灰色的」——**只要大家能够形成图像，就能实现飞速记忆**。

- [ ] 拆分依据用的是哪一种（熟词 / 象形 / 词根词缀 / 谐音 / 拼音 / 整体谐音）？是否说明？
- [ ] 拆出的图像是否和**单词的汉语意思**连成了一句有画面的话？
- [ ] 是否提醒用户去课程方领取配套编码文档（字母编码表 / 拆分联想查询）？
- [ ] 若某字母组合拆不出来，是否**如实说明**并建议自行编码，而不是硬编一个说不通的图？
