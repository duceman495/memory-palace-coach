# 拼音图像库（关键词出图对照表）

把文字转成图像时的**查表工具**。每个拼音对应一个（或几个）谐音图像。

## 怎么用

1. 遇到不会出的字 → 看它的**拼音**（**四个声调都试**，声调不同不影响）
2. 在下面按首字母找到该拼音 → 取其中一个图像
3. **一个拼音只需记住一个图像**，不要贪多
4. 出了图立刻记进**错字本** —— 查表只是过渡，目标是全会

### 多个候选怎么挑（重要）

有的拼音给了 3～6 个候选，按以下顺序选：

1. **首字拼音与被转化的字完全相同**（声调可不同）—— 例：护 hù → 选**胡须**（hú）而不是老虎
2. **图像具体、独立、有大小** —— 避免太泛的（天空、平原）
3. **尽量避开人物图像** —— 人物相似性大（本表中的人物只能靠标志性特征区分）
4. **一旦选定就不再改** —— 稳定性比"最优"更重要

> ⚠️ **这不是唯一答案**。课程原话：
> 「你可以编码不同的图像，**你自己喜欢编哪一个你就用哪一个**，不一定要按照我上面来的。」
> 若某个编码与你的语义联想冲突，或你有更顺手的，**以你自己的为准**。
