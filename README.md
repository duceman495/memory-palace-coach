# memory-palace-coach

把要背的材料转换成**可执行的记忆编码方案**：拆分关键词组 → 关键词出图 → 影像故事连接或定桩，并给出还原检验方法。

这是一个 [Agent Skill](https://agentskills.io/specification)（`SKILL.md` 格式），可用于 Pi、Claude Code 等支持该规范的 agent。

## 它能做什么

给它一段要背的材料，它不会泛泛而谈"多读几遍"，而是产出具体方案：

```
材料判断 → 拆分小段 → 提取关键词组 → 关键词出图 → 选方法 → 编码方案 → 还原检验
```

每条连接都必须满足**直接接触**（"叼着""砸进""插在"，而不是"旁边有""看着"），
每个关键词都必须有**具体、独立、有大小**的图像。

## 覆盖的材料类型

| 类型 | 方法 |
|---|---|
| 并列条目 / 考点 | 影像故事法 |
| 简答题 / 名词解释 | 逐字精确类材料 |
| 文言文 / 古诗 / 文章 | 文字联想定桩法、套娃式分段 |
| 选择题 / 表格 | 应试材料速记 |
| 法条 | 逐字精确类材料（提取粒度从严） |
| 英语单词 | 拆解 → 出图 → 造句 |
| 数字 / 公式 / 地图 | 编码记忆 |
| 流程步骤 | 定桩法（桩序 = 步骤序） |
| 演讲 / 临场 | 轨迹定桩法 |

## 覆盖的方法体系

- **影像故事法** —— 7 条标准 + 图像顺序判断 6 法
- **定桩法** —— 宏观/微观桩子、图像转换（10 条转换规则）、标题联想、文字联想、空间故事（区域桩）、模块、轨迹
- **编码记忆** —— 公式 / 地图 / 数字 / 扑克
- **图像创造技巧** —— 夸张、奇特、大场面、破坏性
- **方法混用** —— 桩子不够时的 5 种混用模式

## 内置的拼音图像库

**“出不了图”是这套方法里最大的卡点。** 所以本 skill 内置了课程配套的《拼音图像库》：

- **398 个拼音 / 1128 个谐音图像**
- 含**高频双字词直出**（维护 → 围巾+胡须、荣誉 → 绒毛+鱼…）
- 给出**多候选如何挑**的规则（优先首字拼音完全相同、避开人物图像）
- 列出**同图多拼音共用**的情况（灰尘/闹钟/龙舟…），避免同段材料撞图

> 这修正了之前版本只能“去课程方领”的缺陷 —— 现在出图步骤是闭环的。
